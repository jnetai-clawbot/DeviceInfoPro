=== Device Info Pro v1.0.0 ===
- Created Android project for comprehensive device information display
- DeviceInfoCollector with 7 categories: Hardware, System, Display, Battery, Storage, Network, Sensors
- Hardware: manufacturer, model, RAM, CPU cores, ABI, /proc/cpuinfo parsing
- System: Android version, SDK, build fingerprint, security patch, runtime memory, device name
- Display: resolution, real resolution, DPI, density bucket, screen size, refresh rate
- Battery: level, status, health, temperature, voltage, technology, charge counter, current
- Storage: internal/external storage with used/free/total, app files/cache dirs
- Network: WiFi SSID/BSSID/signal/speed/frequency/IP/MAC, interfaces, connectivity, telephony
- Sensors: full sensor list with type, vendor, version, power, resolution, max range
- "All Info" button to display everything at once
- AboutActivity with version display, Check for Update, Share App
- ErrorHandler with error codes, timestamps, stack traces, Toast notifications
- DebugLogger with timestamped log output
- Dark theme with #1A1A2E background, #E94560 accent
- Bottom padding (80dp) to prevent button cutoff
- GitHub Actions workflow for automated APK build and release
- Keystore generated and stored as GitHub secret
- Repository: https://github.com/jnetai-clawbot/DeviceInfoPro
- Tag v1.0.0 pushed to trigger release build
